## What I'm building

### Engineering Intelligence

Currently working on **AI orchestration systems for engineering workflows**, including drawing understanding, structured representations, evaluation, execution tracing, and downstream CAD generation.

A 68-drawing benchmark showed:

```text
Reconstruction success     60.6%  →  69.7%
Empty-OCR failures         36.4%  →  15.2%
Hole extraction F1                     0.98
```

The interesting part isn't just getting an LLM to understand a drawing.

It's building the **system around it**.

---

### NagarAI

**AI × Computer Vision × Civic Intelligence**

An AI-powered civic reporting system that turns street-level images into structured infrastructure reports.

```text
Image
  ↓
Vision / Multimodal AI
  ↓
Issue Classification
  ↓
Severity + Affected Area
  ↓
Geospatial Processing
  ↓
Bilingual Civic Report
```

Built with **FastAPI, Qwen2.5-VL, Gemini, PostgreSQL, Next.js and TypeScript**.

---

### Embryo Viability Analysis

**Computer Vision × Machine Learning × Real-time Inference**

Built an inference platform around a **3-model Random Forest ensemble trained on 211K+ images**, with computer-vision feature extraction, leakage-safe SMOTE, confidence scoring and a FastAPI + React interface.

The goal:

**turn image-based biological signals into an actual usable system.**
